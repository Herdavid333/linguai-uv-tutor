# LinguAI UV

LinguAI UV is an AI-powered conversational tutor designed to support English learning for students at Universidad del Valle.

## Features

- Conversational AI tutor
- Grammar feedback
- Vocabulary learning
- Pronunciation practice
- Progress tracking

## Tech stack

Frontend: Next.js + React + Tailwind  
Backend: Node.js  
AI: OpenAI API  
Database: Firebase Firestore
